Small fixes and documentation.

**Upgrading**

- sshd's privilege separation directory `/run/sshd` now comes from
  `ble-term-session@.service` (`RuntimeDirectory=sshd`) instead of a
  tmpfiles line. Debian 13 no longer warns about a duplicate tmpfiles
  entry, and BLE sessions keep working after `ssh.service` was stopped
  (stopping it removes `/run/sshd`).

**Changes**

- Security notes: password guessing and session slot occupation over BLE
  are accepted risks (docs/SECURITY.md, S-3 and S-4); the README recommends
  public keys only.
- Bench notes: Android 8 and 11 clients, Flipper One stops advertising
  while connected, Raspberry Pi Zero 2 W login times.
